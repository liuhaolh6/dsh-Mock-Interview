# ADR-0003 会话存储用文件，不用 storageDomain

- 状态：已接受（2026-11-23）
- 影响：持久化层、测试夹具、迁移策略

## 背景

宿主提供 `storageDomain` 服务，但本会话只验证到它的存在（`open/get/closeAll`），没有拿到 DomainSpec 语义、迁移与并发写的实据。而面试会话是「一次一条、随时中断、要能整份导出」的数据。

## 决策

v1 用文件存储：`$DSH_HOME/storages/dsh-mock-interview/sessions/<id>.json`，
- 写入用「临时文件 + rename」保证原子性；
- 顶层带 `schemaVersion`，读到时版本不匹配则走显式迁移函数，迁移失败即拒绝加载并报错，不静默丢数据；
- 单文件上限 2 MB，超限拒绝继续写入并提示导出结束当前会话。

## 后果

- 好：行为可预测、可直接放进 git 之外的目录备份、测试用临时目录即可覆盖、不依赖未验证的宿主 API。
- 代价：没有宿主级的并发保护，多窗口同时写同一会话由「最后写赢」兜底（UI 已串行化提交）。
- 迁移路径：若日后 `storageDomain` 的语义明确且支持事务，写一个一次性迁移脚本，`schemaVersion` 递增，旧文件保留为只读备份。
